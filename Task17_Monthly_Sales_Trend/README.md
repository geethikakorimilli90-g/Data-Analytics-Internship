# Task 17 — Monthly Sales Trend Analysis

## Project Overview
This project summarizes monthly sales data and visualizes sales trends using Microsoft Excel and Python.

## Objective
- Summarize total sales by month.
- Practice date conversion and monthly grouping.
- Create a monthly sales summary table.
- Visualize sales trends using a line chart.

## Tools and Technologies
- Microsoft Excel
- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Dataset
The dataset contains sales transaction records with order dates, products, categories, regions, quantities, unit prices, and sales values.

## Project Workflow
1. Imported the sales dataset.
2. Checked and converted order dates.
3. Grouped sales data by month.
4. Calculated total monthly sales.
5. Created a monthly summary table in Excel and Python.
6. Created a line chart to visualize the monthly sales trend.
7. Exported the monthly summary and chart for submission.

## Deliverables
- Original sales dataset in CSV format
- Excel analysis workbook
- Python Jupyter notebook
- Monthly sales summary CSV
- Monthly sales trend chart in PNG format

## Key Learning Outcomes
- Date handling and conversion
- Monthly data aggregation
- Chronological sorting
- PivotTable analysis in Excel
- Line chart visualization
- Exporting analysis results

## Conclusion
This project demonstrates how monthly sales data can be analyzed and visualized using Excel and Python. The monthly summary and line chart help identify changes in sales performance over time.
