# Task 07 - First Chart Story: Turning Numbers into a Narrative

## Project Overview

This project focuses on turning the Iris dataset into a simple visual story using Microsoft Excel.

The objective is to use different charts to compare values, show distribution, and communicate key insights clearly.

## Tool Used

- Microsoft Excel

## Dataset

**Iris Dataset**

The dataset contains measurements of:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

The dataset contains three species:

- Setosa
- Versicolor
- Virginica

## Charts Created

### 1. Average Petal Length by Iris Species

**Chart Type:** Bar Chart

**Question:** Which Iris species has the highest average petal length?

**Insight:** Iris-virginica has the highest average petal length.

### 2. Iris Species Distribution

**Chart Type:** Pie Chart

**Question:** How is the Iris dataset distributed across species?

**Insight:** All three species have an equal number of observations.

### 3. Average Sepal Length by Iris Species

**Chart Type:** Column Chart

**Question:** Which Iris species has the highest average sepal length?

**Insight:** Iris-virginica has the highest average sepal length.

## Key Findings

- Iris-virginica has the highest average petal length.
- Iris-virginica has the highest average sepal length.
- All three species have an equal number of observations.
- The charts make comparisons between the three species easy to understand.

## Overall Story

The Iris dataset shows clear differences between the three species. Iris-virginica has the highest average petal length and average sepal length. All three species have an equal number of observations, making the comparison balanced. The charts transform the raw measurements into a simple and meaningful visual story.

## Interview Questions

### 1. When would you choose a bar chart over a line chart?

A bar chart is useful for comparing values across different categories. A line chart is better for showing trends or changes across an ordered sequence, especially over time.

### 2. Why are pie charts often discouraged in professional reporting?

Pie charts can be difficult to compare when there are many categories or when the values are very similar. Bar charts usually make comparisons easier. Pie charts are best used when there are only a few categories and the purpose is to show a part-to-whole relationship.

## Conclusion

This project demonstrates how Excel charts can transform raw data into a clear and meaningful visual story.
