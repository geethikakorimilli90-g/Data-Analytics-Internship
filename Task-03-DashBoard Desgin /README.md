# Task 3 – Simple Sales Dashboard Design

## Project Overview

This project is a simple interactive sales dashboard created using the Sample Superstore dataset.

The dashboard provides an overview of sales performance by product, region, and month. It converts the cleaned sales data into an interactive visual dashboard that can be used to understand important sales trends and performance indicators.

## Tools Used

- Microsoft Power BI
- Excel / CSV
- Google Colab
- Python (for data preparation and cleaning)

## Dataset

The dashboard uses the Sample Superstore sales dataset.

The dataset contains information such as:

- Order Date
- Product Name
- Region
- Sales
- Profit
- Quantity
- Customer and order details

## Key Performance Indicators (KPIs)

The dashboard displays three main KPIs:

1. Total Sales
2. Total Profit
3. Units Sold

These KPIs provide a quick overview of the overall sales performance.

## Dashboard Visuals

The dashboard contains the following visualizations:

### 1. Sales by Region
Shows the total sales generated by different regions.

### 2. Sales by Product
Shows sales performance across products and highlights products with higher sales.

### 3. Monthly Sales Trend
Shows how sales change from month to month.

## Interactive Filters

The dashboard includes two filters:

- Region Filter
- Month Filter

Users can select a specific region or month to interactively analyze the sales data.

## How to Read the Dashboard

Start with the KPI cards at the top to understand the overall sales, profit, and units sold.

Next, use the Sales by Region chart to compare regional performance.

The Sales by Product chart helps identify products with higher sales.

The Monthly Sales Trend chart shows how sales vary over time.

The Region and Month filters can be used to view the dashboard for a specific region or month.

## Key Insights

- Sales performance varies across different regions.
- Some products contribute more significantly to total sales than others.
- Monthly sales show variation throughout the year.
- The interactive filters allow users to analyze sales performance based on region and month.
