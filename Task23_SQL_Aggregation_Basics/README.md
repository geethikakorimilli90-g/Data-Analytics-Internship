# Task 23 - SQL Aggregation Basics

## Project Overview
This project focuses on learning and practicing SQL aggregate functions to summarize and analyze data.

## Objective
To understand and implement SQL aggregation functions such as COUNT(), SUM(), AVG(), MIN(), and MAX(), along with GROUP BY and NULL handling.

## Tools Used
- MySQL / PostgreSQL
- Google Colab
- Jupyter Notebook
- GitHub

## Dataset
The project uses an employee dataset containing employee details, department information, and salary values.

## SQL Concepts Covered
- COUNT() – Counts records.
- SUM() – Calculates the total value.
- AVG() – Calculates the average value.
- MIN() – Finds the minimum value.
- MAX() – Finds the maximum value.
- GROUP BY – Groups records by department or category.
- NULL Handling – Understands how aggregate functions handle missing values.

## Tasks Completed
- Created SQL aggregation queries.
- Practiced COUNT, SUM, AVG, MIN, and MAX functions.
- Applied GROUP BY to summarize data by department.
- Checked NULL handling using aggregate functions.
- Saved the SQL queries and notebook for reference.
