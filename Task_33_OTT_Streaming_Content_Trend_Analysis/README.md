# OTT Streaming Content Trend Analysis

## Project Overview
This project focuses on analyzing OTT (Over-The-Top) streaming content from Netflix, Amazon Prime Video, and Disney+ Hotstar.

The main objective is to explore content distribution, identify popular genres, analyze release-year trends, and compare the content libraries of different streaming platforms using Python, SQL, and data visualization techniques.

## Project Objectives
- Analyze OTT streaming content across different platforms.
- Compare Movies and TV Shows.
- Identify the most common content genres.
- Analyze content release-year trends.
- Explore country-wise content distribution.
- Understand content rating distribution.
- Generate actionable business insights.

## Tools and Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL (SQLite)
- GitHub

## Datasets
The project uses three OTT content datasets:

1. Netflix Movies and TV Shows
2. Amazon Prime Movies and TV Shows
3. Disney+ Hotstar Movies and TV Shows

The datasets were combined into a single dataset for comparative analysis.

## Project Workflow

### 1. Data Collection
Collected OTT streaming datasets from different platforms.

### 2. Data Preparation
Combined the datasets and standardized common column names.

### 3. Data Cleaning
- Handled missing values.
- Removed duplicate records.
- Standardized text columns.
- Converted columns into appropriate data types.
- Extracted movie duration information.

### 4. Exploratory Data Analysis (EDA)
Performed exploratory analysis to understand content distribution and patterns.

### 5. Data Visualization
Created visualizations covering:

- Content Type Distribution
- Platform-wise Content Count
- Top 10 Popular Genres
- Content Release Year Trend
- Top 10 Countries by Content
- Content Rating Distribution
- Movie Duration Analysis

### 6. SQL Analysis
Used SQLite to perform:
- Platform-wise content aggregation.
- Movies and TV Shows comparison.
- Release-year analysis.
- SQL JOIN operations.
- Content rating aggregation.

### 7. Business Insights
Identified three key areas:

- Platform Content Strategy
- Genre Analysis
- Content Release Trends

Provided recommendations based on the analysis.

## Project Deliverables
- Python Jupyter Notebook (`.ipynb`)
- Combined OTT Dataset (`.csv`)
- Cleaned OTT Dataset (`.csv`)
- SQL Analysis Queries (`.sql`)
- Content Strategy Memo (`.md`)

## Conclusion
This project demonstrates how Python, SQL, and data visualization can be used to analyze OTT streaming catalogs. The analysis provides insights into platform-wise content availability, genre distribution, and release-year patterns that can support content strategy and catalog planning.
