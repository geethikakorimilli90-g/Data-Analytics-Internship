# Task 27: Date Cleaning Basics

## Project Overview
This task focuses on cleaning and standardizing date formats in a Retail Sales dataset. Consistent date formats are important for accurate data analysis, sorting, filtering, and time-based reporting.

## Objective
- Identify inconsistent date formats.
- Standardize valid dates into a consistent format.
- Identify invalid and missing dates.
- Maintain an issue log to document data quality problems and actions taken.

## Tools Used
- Microsoft Excel
- Retail Sales Dataset

## Dataset
The Retail Sales dataset is used to practice date cleaning and validation. The original date values are preserved for comparison with the cleaned dates.

## Tasks Performed
1. Inspected the date column for inconsistent formats.
2. Created a separate column for cleaned dates.
3. Converted recognizable date values into a consistent date format (`DD-MM-YYYY`).
4. Checked for invalid and missing date values.
5. Created a Date Status column to classify date values.
6. Prepared an Issue Log to document identified problems and corrective actions.
7. Preserved the original date values to support verification.

## Data Quality Checks
- Checked whether dates were recognized correctly by Excel.
- Verified the consistency of the displayed date format.
- Identified missing and invalid values for further review.
- Avoided making assumptions about ambiguous dates.

## Deliverables
- `Task27_Date_Cleaning_Basics.xlsx` — cleaned dataset and issue log.
- `README.md` — project documentation.

## Key Learnings
- Importance of consistent date formats in data analysis.
- How to use Excel tools to clean and validate dates.
- How to identify invalid and missing date values.
- Importance of documenting data quality issues.

## Conclusion
This task provided practical experience in date cleaning, standardization, validation, and issue documentation using Microsoft Excel. The cleaned data is better prepared for further analysis and reporting.
