# Task 21: Basic SQL SELECT

## Objective
The objective of this task is to learn basic SQL SELECT queries and retrieve data from customer and product datasets using SQLite.

## Tools Used
- Google Colab
- Python
- SQLite
- Pandas
- SQL

## Datasets
- `customers.csv`
- `products.csv`

## Tasks Performed
1. Retrieved all customer records using SELECT.
2. Selected specific columns from the Customers table.
3. Filtered customers by city using WHERE.
4. Filtered customers by country using WHERE.
5. Sorted customers by company name using ORDER BY.
6. Retrieved all records from the Products table.
7. Filtered products with a unit price below 20.
8. Filtered products with a unit price above 20.
9. Sorted products by unit price in descending order.
10. Retrieved the five cheapest products using LIMIT.

## SQL Concepts Covered
- SELECT
- WHERE
- ORDER BY
- ASC and DESC
- LIMIT

## Files Included
- `Task21_Basic_SQL_SELECT.ipynb` – Contains the SQL queries and outputs.
- `customers.csv` – Customer dataset.
- `products.csv` – Product dataset.

## Outcome
Practiced retrieving, filtering, and sorting customer and product data using SQL queries in SQLite.

## Conclusion
This task provided practical experience with basic SQL SELECT statements and data retrieval operations.
