# Task 06 - Excel Formulas & Functions Fundamentals

## Project Overview

This project demonstrates commonly used Excel formulas and functions
for analyzing a small retail sales dataset.

The objective of this task is to build practical Excel skills used
in real-world data analysis and reporting.

## Tools Used

- Microsoft Excel
- GitHub

## Dataset

The dataset contains retail transaction information including:

- Order ID
- Date
- Product ID
- Customer
- Region
- Quantity
- Sales

## Excel Functions Used

### Lookup Functions
- VLOOKUP
- XLOOKUP
- INDEX/MATCH

### Logical Function
- IF

### Aggregation Functions
- SUMIF
- SUMIFS

### Counting Functions
- COUNTIF
- COUNTIFS

### Text Functions
- LEFT
- RIGHT
- CONCAT

## Analysis Performed

- Retrieved product names using VLOOKUP
- Retrieved product information using XLOOKUP
- Classified sales using IF
- Calculated region-wise sales using SUMIF
- Calculated sales using multiple conditions with SUMIFS
- Counted records using COUNTIF and COUNTIFS
- Extracted text using LEFT and RIGHT
- Combined text using CONCAT
- Performed flexible lookups using INDEX/MATCH

## Edge Case Testing

The formulas were tested with:

- Blank Product IDs
- Invalid Product IDs
- Text-versus-number mismatches

## Project Files

- `Task-06-Excel-Formulas.xlsx` - Excel workbook containing the retail dataset, formulas, practice examples, notes, and edge-case testing.

## Key Learning

This project helped demonstrate practical Excel skills for data
lookup, conditional calculations, aggregation, counting, and
text manipulation.

## Outcome

Successfully practiced core Excel functions commonly used by
data analysts for everyday data analysis and reporting.
