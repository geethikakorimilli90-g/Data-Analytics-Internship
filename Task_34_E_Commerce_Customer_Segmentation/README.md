# E-Commerce Customer Segmentation Using RFM Analysis

## 1. Project Overview

This project focuses on analyzing e-commerce customer purchasing behaviour using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering.

The main objective is to identify different customer groups based on their purchasing patterns and provide useful business insights.

## 2. Project Objectives

- Analyze customer purchasing behaviour.
- Calculate Recency, Frequency and Monetary values.
- Assign RFM scores to customers.
- Identify customer segments.
- Apply K-Means clustering.
- Build an interactive Power BI dashboard.
- Generate business recommendations.

## 4. Methodology

### Data Collection
Collected the e-commerce transaction dataset from Kaggle.

### Data Cleaning
- Removed duplicate records.
- Handled missing customer IDs.
- Removed cancelled transactions.
- Removed invalid quantity and price values.

### RFM Analysis
Calculated:
- Recency – Days since the last purchase.
- Frequency – Number of unique invoices.
- Monetary – Total customer spending.

### Customer Segmentation
Assigned RFM scores and grouped customers into different segments.

### K-Means Clustering
Applied the K-Means algorithm to identify customer clusters.

### Dashboard Development
Created a Power BI dashboard to visualize customer segments, purchasing behaviour and cluster distribution.
