# Superstore Sales Analysis

## Project Overview

This project analyzes Superstore sales data to identify sales and profit performance across different categories and regions.

## Objectives

- Analyze total sales, profit, and quantity
- Compare sales performance by category
- Compare sales performance by region
- Analyze order-date sales performance
- Identify key business insights

## Tools Used

- Microsoft Excel
- PivotTables
- Excel formulas
- Data Analysis

## Key Analysis

### KPI Analysis
- Total Sales: 2,297,200.86
- Total Profit: 286,397.02
- Total Quantity: 37,873

### Category Analysis

The analysis compares Furniture, Office Supplies, and Technology based on total sales, record count, and average sales.

### Regional Analysis

Sales performance was analyzed across Central, East, South, and West regions using PivotTables.

## Key Findings

Technology generated the highest sales among the three categories. Office Supplies had the lowest average sales. Regional analysis showed differences in sales performance across the four regions.
