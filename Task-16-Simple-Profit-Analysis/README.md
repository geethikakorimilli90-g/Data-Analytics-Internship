# Task 16: Simple Profit Analysis

## Project Overview
This project analyzes total profit across product categories using Microsoft Excel.

## Objective
To compare total profit across Furniture, Office Supplies, and Technology and understand basic profitability.

## Dataset
The dataset contains the following columns:
- Order ID
- Category
- Sub-Category
- Sales
- Cost
- Profit

## Tools Used
- Microsoft Excel
- PivotTable
- Column Chart
- GitHub

## Methodology
1. Imported the dataset into Excel.
2. Created a PivotTable to group profit by category.
3. Calculated total profit for each category.
4. Created a column chart to compare category-wise profit.
5. Identified the highest- and lowest-profit categories.

## Results
| Category | Total Profit |
|---|---:|
| Furniture | 2685 |
| Office Supplies | 780 |
| Technology | 4315 |
| **Grand Total** | **7780** |

Technology recorded the highest total profit, while Office Supplies recorded the lowest total profit in this practice dataset.

## Conclusion
This task helped me practice Excel PivotTables and charts to summarize and compare profitability across product categories.

## Deliverables
- Excel workbook containing the dataset and profit summary.
- Column chart showing total profit by product category.
- Chart screenshot for reference.
