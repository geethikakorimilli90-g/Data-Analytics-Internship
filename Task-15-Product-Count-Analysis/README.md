
# Task 15 — Product Count Analysis

## Task Name
Product Count Analysis

## Objective
To count products by category and identify the category with the highest product count using Microsoft Excel.

## Tools Used
- Microsoft Excel
- GitHub

## Dataset
File Name: `Task15_Product_Count_Dataset.csv`

The dataset contains Product ID, Product Name, Category, Sub-Category, Unit Price, Stock Qty, and Estimated Profit.

## Methodology
1. Loaded the product dataset into Excel.
2. Identified the different product categories.
3. Used the COUNTIF function to count products in each category.
4. Used the MAX function to find the highest product count.
5. Used INDEX and MATCH functions to identify the top category.
6. Verified the final results.

## Product Count Analysis

| Category | Product Count |
|---|---:|
| Furniture | 10 |
| Office Supplies | 12 |
| Technology | 8 |

## Key Findings
- Office Supplies has the highest product count.
- The highest product count is 12.
- Excel formulas helped perform category-wise product analysis.
