# Task 19 – Top 10 Products

## Description
Identify the top 10 products using the Superstore dataset.

## Objective
Practice ranking and sorting techniques to find the top 10 products.

## Tools Used
- Microsoft Excel
- Python

## Dataset
**Dataset Name:** Superstore

The Superstore dataset is used to analyze product information and identify the top 10 products.

## Steps Performed
1. Loaded the Superstore dataset.
2. Checked the product names and relevant data.
3. Sorted the products based on the selected ranking criteria.
4. Identified the top 10 products.
5. Prepared a Top 10 table.
6. Created a chart to visualize the results.
7. Checked for ties in the ranking.

## Deliverables
- Top 10 Products table
- Chart

## Key Learnings
- Practiced sorting data in descending order.
- Learned how to rank products.
- Understood how to handle ties.
- Improved data analysis and visualization skills.

## Interview Questions

### 1. How do you handle ties?
Ties can be handled by assigning the same rank to products with equal values or by using a consistent tie-breaking rule.

### 2. Why use Top 10 analysis?
Top 10 analysis helps identify leading products and makes data easier to understand.

## Conclusion
This task helped me practice ranking and sorting techniques using Excel and Python to identify the top 10 products and present the results in a table and chart.
