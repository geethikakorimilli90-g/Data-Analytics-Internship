# Task 26: Text Cleaning Basics

## Objective
To standardize customer names and city names by removing extra spaces and correcting capitalization.

## Tools Used
- Microsoft Excel
- Python
- Pandas
- Google Colab

## Dataset
A sample customer dataset containing customer IDs, customer names, email addresses, and cities.

## Cleaning Operations
- Removed leading and trailing spaces.
- Standardized capitalization using Excel and Python.
- Replaced non-breaking spaces.
- Removed repeated whitespace between words.
- Created before-and-after examples to compare the results.
- Exported the cleaned dataset to Excel and CSV formats.

## Files Included
- `Task-26-Text-Cleaning-Dataset.xlsx` – Original dataset
- `Task-26-Cleaned-Dataset.xlsx` – Cleaned Excel dataset
- `Task_26_Text_Cleaning.ipynb` – Python notebook
- `cleaned_customer_dataset.csv` – Cleaned dataset in CSV format
- `before_after_examples.csv` – Before-and-after comparison

## Conclusion
This project demonstrates basic text-cleaning techniques using Excel and Python. The cleaning process improves consistency and readability, making customer data easier to analyze.
