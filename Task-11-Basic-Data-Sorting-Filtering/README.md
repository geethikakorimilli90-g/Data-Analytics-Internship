## Interview Questions

**1. When would you use filtering instead of deleting rows?**

Filtering lets us display only the records we need while keeping the original data unchanged.

**2. Why should raw data be preserved?**

Preserving raw data allows us to check the original records and repeat the analysis whenever needed.
