Task 29: Basic Conditional Formatting

Objective

To improve report readability by automatically highlighting the top and bottom sales values using Microsoft Excel.

Tool Used

- Microsoft Excel

Dataset

Retail Sales Dataset

Work Completed

- Opened the retail sales dataset in Excel.
- Applied the Top 10 Items conditional formatting rule.
- Applied the Bottom 10 Items conditional formatting rule.
- Highlighted the highest and lowest values in the TotalSales column.
- Created a separate Rules_List worksheet to document the formatting rules.
- Tested the rules and saved the final workbook.

Key Learning

Conditional formatting helps identify high and low values quickly without manually applying colors. It makes reports easier to read and understand.

Files Included

- "Task-29-Conditional-Formatting.xlsx" — Formatted Excel workbook with the rules list.

Conclusion

This task demonstrates how Excel conditional formatting can automatically highlight important sales values and improve report readability.
