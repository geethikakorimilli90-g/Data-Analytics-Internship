# Task 17 — Top 10 Products by Sales

## Project Overview
This project identifies the top 10 products based on total sales using a Superstore sales dataset. The results are analyzed and visualized using Microsoft Excel, Python, Google Colab, and Power BI.

## Objective
- Analyze product-wise sales.
- Calculate total sales for each product.
- Identify the top 10 products with the highest sales.
- Visualize sales performance using charts.
- Export the results for further analysis.

## Tools and Technologies
- Microsoft Excel
- Google Colab
- Python
- Pandas
- Matplotlib
- Microsoft Power BI
- GitHub

## Dataset
The original Superstore sales dataset used for the Excel analysis was also used for the Python analysis and Power BI report.

## Project Workflow
1. Loaded the Superstore dataset.
2. Checked dataset columns, missing values, and duplicate records.
3. Grouped the data by product name.
4. Calculated total sales for each product.
5. Sorted products in descending order of sales.
6. Selected the top 10 products.
7. Created a PivotTable and chart in Excel.
8. Used Python and Pandas in Google Colab to analyze sales.
9. Created a bar chart using Matplotlib.
10. Created a Top 10 Products by Sales report in Power BI.
11. Exported the top 10 results to a CSV file.

## Project Files
- `Task_17_Top_10_Products_by_Sales.xlsx` — Excel PivotTable and chart.
- `Task_17_Top_10_Products_by_Sales.ipynb` — Python code, analysis, and visualizations.
- `Task_17_Top_10_Products.csv` — Exported top 10 product sales results.
- `Task_17_Top_10_Products_by_Sales.pbix` — Power BI report.

## Key Outcome
Identified the top 10 products based on total sales and presented the results in tables and charts.

## Conclusion
This project provided practical experience in data analysis, sorting, filtering, PivotTables, data visualization, and reporting using Excel, Python, Google Colab, and Power BI.
