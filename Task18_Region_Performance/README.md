# Task 18: Region Performance Analysis

## Project Overview
This project analyzes and compares sales and profit across different regions using Microsoft Excel and Power BI.

## Objective
- Analyze total sales by region.
- Compare total profit across regions.
- Rank regions based on sales and profit.
- Identify high-performing and low-performing regions.
- Present insights using charts and an interactive Power BI dashboard.

## Dataset
The project uses a sample sales dataset containing order details, region, state, product category, sales, and profit.

## Tools Used
- Microsoft Excel
- Microsoft Power BI Desktop
- GitHub

## Project Process
1. Imported and reviewed the raw dataset.
2. Created a PivotTable in Excel to summarize sales and profit by region.
3. Ranked regions based on sales and profit.
4. Created a bar chart to compare regional performance.
5. Built a Power BI dashboard with Total Sales and Total Profit cards, regional charts, and a region slicer.
6. Tested the slicer to verify interactive filtering.

## Key Findings
- Central recorded the highest total sales in the sample dataset.
- East recorded the highest total profit.
- West recorded the lowest total sales and profit.
- The region with the highest sales was not the region with the highest profit.

## Deliverables
- Raw dataset
- Excel analysis workbook
- Power BI dashboard
- Dashboard screenshot

## Conclusion
This project demonstrates data summarization, regional performance comparison, ranking, and interactive visualization using Excel and Power BI.
