# Task 22: SQL Filtering Practice Using Northwind Database

## 📌 Project Overview
This project focuses on practicing SQL filtering techniques using the Northwind sample database. SQL queries are used to retrieve specific records based on conditions and to understand how filtering operators work.

## 🎯 Objective
- Practice SQL queries using the `WHERE` clause.
- Filter records using comparison and logical operators.
- Apply `IN`, `NOT IN`, `BETWEEN`, and `NOT BETWEEN`.
- Search for text patterns using the `LIKE` operator.
- Execute queries and analyze the returned results.

## 📂 Dataset
**Dataset Name:** Northwind Sample Database

The Northwind database contains sample business data, including customer, order, product, and supplier information.

**Table Used:** Customers

**Dataset Format:** SQLite database (`.sqlite`)

## 🛠️ Tools and Technologies
- Google Colab
- Python
- SQLite
- Pandas
- SQL

## 🔍 SQL Queries Performed

1. Filter customers using `WHERE`.
2. Filter customers by city.
3. Exclude a selected country using `<>`.
4. Combine conditions using `AND`.
5. Filter using alternative conditions with `OR`.
6. Select records using `IN`.
7. Exclude multiple values using `NOT IN`.
8. Select a range using `BETWEEN`.
9. Exclude a range using `NOT BETWEEN`.
10. Find names starting with a specific letter using `LIKE`.
11. Find names ending with a specific letter using `LIKE`.
12. Search names containing a specified pattern using `LIKE`.

## ⚙️ Methodology

1. Downloaded the Northwind SQLite database.
2. Uploaded the database into Google Colab.
3. Connected to the database using Python's SQLite library.
4. Inspected the available tables and columns.
