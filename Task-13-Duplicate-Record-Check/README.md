# Task 13: Duplicate Record Check

## Objective
Identify duplicate records and create a cleaned dataset using Microsoft Excel.

## Tools Used
- Microsoft Excel

## Dataset
Practice Sales Dataset

## Process
1. Imported the dataset into Excel.
2. Preserved the original data in the `Raw_Data` sheet.
3. Created a copy named `Cleaned_Data`.
4. Identified exact duplicate rows using the Remove Duplicates feature.
5. Removed duplicate rows from the copied dataset.
6. Created a `Duplicate_Report` sheet to document the results.

## Results
- Original Records: 34
- Duplicate Records Removed: 4
- Cleaned Records: 30

## Deliverables
- Original dataset
- Cleaned dataset
- Duplicate report and audit note

## Conclusion
This project demonstrates how to identify and remove duplicate records while preserving the original dataset for reference.
