# Task 31 – Employee Data Summary

## 1. Project Overview

The Employee Data Summary project focuses on analyzing employee information using Microsoft Excel. The main objective is to understand workforce distribution across different departments and job roles and compare employee salary information.

This project uses Excel PivotTables, PivotCharts, and statistical functions to organize, summarize, and visualize employee data.

## 2. Project Objectives

- Analyze the total number of employees in each department.
- Understand employee distribution across different job roles.
- Calculate average monthly salary for each department.
- Calculate the overall median and average salary.
- Compare salary differences between departments.
- Create meaningful charts to present workforce insights.
- Practice grouped data analysis using Excel PivotTables.

## 3. Dataset Information

**Dataset Name:** IBM HR Analytics Employee Attrition & Performance

**Dataset Source:** Kaggle

**Dataset Description:**

The dataset contains employee-related information, including personal, professional, departmental, and salary details.

**Important Columns Used:**

| Column Name | Description |
|---|---|
| EmployeeNumber | Unique employee identification number |
| Department | Department where the employee works |
| JobRole | Employee's job position |
| MonthlyIncome | Monthly salary of the employee |
| Age | Employee age |
| Gender | Employee gender |
| YearsAtCompany | Years spent in the company |

**Dataset Size:** 1,470 employee records and 35 columns.

## 6. Analysis Performed

### A. Department-wise Employee Count

- Grouped employees based on department.
- Calculated the total employee count in each department.
- Compared workforce distribution across departments.

### B. Job Role-wise Employee Count

- Grouped employees according to their job roles.
- Calculated the number of employees in each role.
- Identified the distribution of different job positions.

### C. Department-wise Average Salary

- Grouped employees by department.
- Used the Average aggregation in PivotTable.
- Calculated and compared average monthly income across departments.

### D. Salary Analysis

- Calculated overall average monthly salary.
- Calculated median monthly salary using the MEDIAN function.
- Compared average and median salary to understand salary distribution.

## 9. Importance of Median Salary

Median salary represents the middle value when all employee salaries are arranged in ascending order.

It is useful because unusually high or low salaries can affect the average salary. Median provides a better understanding of the typical salary in such situations.
