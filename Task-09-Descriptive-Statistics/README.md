# Task 09 – Descriptive Statistics Primer

## Objective

Calculate and interpret descriptive statistics for numerical columns in a dataset.

## Tools Used

* Microsoft Excel

## Dataset

Titanic-style passenger dataset.

## Statistics Calculated

* Count
* Mean
* Median
* Mode
* Standard Deviation
* Minimum and Maximum
* 25th, 50th, and 75th Percentiles

## Key Findings

* The average passenger age is approximately 32.02 years.
* Fare has a mean greater than its median, suggesting right skewness.
* Fare values show considerable variation.
* Percentiles help describe the spread of passenger fares.

## Conclusion

This project demonstrates how descriptive statistics help summarize numerical data and understand its distribution, spread, and skewness.
